# 용어집

| 용어 | 뜻 |
|------|----|
| LLM | Large Language Model(대규모 언어 모델). fact extraction과 summarization을 수행하는 모델 경계. |
| MEM | Memory(기억). naia-memory 요구사항 식별자의 영역 접두사. |
| AUTH | Authentication(인증). 전송 대상에 맞는 credential header 선택 영역. |
| IDEMP | Idempotency(멱등성). 같은 episode ID 재시도가 중복 항목을 만들지 않는 성질. |
| NFR | Non-Functional Requirement(비기능 요구사항). 보안·동시성·자원 수명 같은 품질 계약. |
| SEC | Security(보안). credential 격리와 비노출 요구사항 접두사. |
| P04 | V-model의 통합 테스트·검증 단계. |
| P05 | 검증된 요구사항을 완료 상태로 닫는 단계. |
| F13 | 프로젝트 루트에서 허용하는 파일 이름의 화이트리스트 규칙. |
