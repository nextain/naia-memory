# 임베딩 검색 방식 비교: 한국어 공개 검색 시험과 대화 기억 회상

## 목적

나이아 메모리의 검색 단계에서 임베딩 모델을 바꿨을 때 검색 품질, 메모리 사용량, 질의 시간을 비교했다. 공개 검색 시험 세 묶음과 대화 기억 회상 시험을 사용했다.

## 설정

- 검색 모델: 키워드 검색, MiniLM, 다국어 MiniLM, Qwen3 임베딩 0.6B, Kanana 임베딩 1.3B와 3B
- 평가 자료: SciFact·NFCorpus·FiQA 한국어·영어 세트 및 LoCoMo 대화 기억 회상 시험 (대화 10개, 질의 1,973건)
- 채점: nDCG@10 점수를 썼다. 공개 검색 시험의 세 과제 평균을 언어별로 집계하고, LoCoMo는 별도 집계했다.
- 하드웨어: 임베딩 모델은 GPU에서 실행하고, 기존 MiniLM 선택지는 CPU에서 실행했다. 메모리·질의 시간은 실행 중 관측값이다.

## 결과

점수가 높을수록 검색 순위가 기준에 가깝다.

| 검색 방식 | 한국어 평균 | 영어 평균 | 대화 기억 회상 | 전체 평균 | GPU 메모리 | 질의 시간 |
|---|---:|---:|---:|---:|---:|---:|
| 키워드 검색 | 0.420 | 0.458 | 0.406 | 0.434 | 미사용 | 41ms |
| MiniLM | 0.062 | 0.505 | 0.284 | 0.283 | CPU 사용 | 4ms |
| 다국어 MiniLM | 0.104 | 0.199 | 0.325 | 0.176 | CPU 사용 | 6ms |
| Qwen3 임베딩 0.6B | 0.439 | 0.571 | 0.460 | 0.499 | 1.7GB | 35ms |
| Kanana 임베딩 1.3B, 1280차원 | 0.520 | 0.556 | 0.516 | 0.535 | 3.3GB | 20ms |
| Kanana 임베딩 1.3B, 512차원 | 0.497 | 0.535 | 0.444 | 0.506 | 3.3GB | 20ms |
| Kanana 임베딩 3B, 2560차원 | 0.527 | 0.578 | 0.475 | 0.542 | 6.5GB | 20ms |

E5 대형 다국어 모델은 SciFact 한국어 과제로 따로 쟀다. nDCG@10은 E5 0.510, 키워드 검색 0.657, Kanana 1.3B 0.711, Kanana 3B 0.760이었다.

## 다음에 잴 것

실제 사용자 기억으로 회상 정확도를 확인하고, 임베딩 서버를 포함한 전체 응답 시간을 잰다. 기기별 메모리 사용량과 E5 전체 과제도 측정한다.

## 재현 방법

시험 자료는 모두 공개 데이터셋이다. nDCG@10 계산은 공개 저장소의 `src/benchmark/quality/retrieval-metrics.ts` 를 쓴다. 이번 조건을 고정한 실행 대본과 설정 파일은 아래 공개 예정 파일로 올린다.

## 공개 예정 파일

- SciFact·NFCorpus·FiQA 한국어·영어 전처리 및 평가 설정
- LoCoMo 10개 대화·1,973개 질의 평가 설정과 nDCG@10 계산 설정
- 모델 버전, 임베딩 차원, GPU·CPU 측정을 고정하는 실행 대본
