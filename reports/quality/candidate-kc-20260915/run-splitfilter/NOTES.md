# 분리 필터 탐색 확인 (증거 아님)

확인 보유셋은 이미 결과를 본 자료이므로 이 실행은 탐색이다. 사전 등록은 없다. 제품은 366141b(규칙 묶음과 R3)에 분리 필터(82e7d5d)를 올린 것이다. 분리 필터는 살아 있는 사실의 앵커가 아니면서 archive된 사실의 원천인 에피소드만 최신 회상에서 뺀다. 규칙 전 실행의 봉인 추출을 재생했고, 삭제 검증·LLM 필터·답변·판정은 실제로 호출했다. 사실 상태는 원문 제외 필터 실행과 648/648행 같다.

## 답변 (판정 모델, 사람 검수 전)

휴리스틱 모순 필터 경로의 결과는 다음과 같다.

- **현재 정답(126문항):** 규칙 전 107, 원문 제외 필터 105, 분리 필터 114.
- **전체 정답(162문항):** 126, 127, 141.
- **삭제 누출(60건):** 20, 3, 7.

LLM 모순 필터 경로의 결과는 다음과 같다.

- **현재 정답:** 114, 107, 109.
- **전체 정답:** 136, 130, 135.
- **삭제 누출:** 17, 4, 4.

원문 제외 필터 대비 분리 필터에서 행이 바뀐 곳은 다음과 같다.

- **동시 선호(coexist):** 휴리스틱 경로 6건, LLM 경로 7건이 정답으로 돌아왔다. 잘못 대체된 선호의 원래 발화가 다시 공급되었기 때문이다.
- **정정(update/correction):** 휴리스틱 경로 4건, LLM 경로 5건이 오답으로 돌아갔다. 대체로 은퇴한 옛 값 발화가 다시 공급되었기 때문이다.
- **비밀값 삭제(delete/forget):** 휴리스틱 경로 5건, LLM 경로 2건이 정답이 되었다.

노이즈 기준인 simple-vector 팔은 공급 맥락이 같은데도 현재 정답이 110, 115, 114로 움직였다. 따라서 5건 안팎의 차이는 노이즈 범위다.

## 해석

분리 필터는 원문 제외 필터의 두 효과를 은퇴 경로에 따라 나눈 결과와 맞는다. 삭제 누출은 대부분 낮게 유지되고, 대체 오류가 남은 동시 선호의 손실은 사라지며, 정정 사례의 옛 값 차단 효과는 일부 잃는다. 이 탐색에서는 세 방식 가운데 전체 정답이 가장 높았다. 기본값으로 정하려면 새 보유셋에서 사전 등록한 확인이 필요하다.
