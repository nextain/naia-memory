# 분리 필터 탐색 확인 (증거 아님)

확인 보유셋은 이미 결과를 본 자료이므로 이 실행은 탐색이다. 사전 등록은 없다. 제품은 366141b(규칙 묶음과 R3)에 분리 필터(82e7d5d)를 올린 것이다. 분리 필터는 살아 있는 사실의 앵커가 아니면서 archive된 사실의 원천인 에피소드만 최신 회상에서 뺀다. 규칙 전 실행의 봉인 추출을 재생했고, 삭제 검증·LLM 필터·답변·판정은 실제로 호출했다. 사실 상태는 원문 제외 필터 실행과 648/648행 같다.

## 답변 (판정 모델, 사람 검수 전)

휴리스틱 모순 필터 경로의 결과는 다음과 같다.

- **현재 정답(126문항):** 규칙 전 107, 원문 제외 필터 105, 분리 필터 114.
- **전체 정답(162문항):** 126, 127, 141.
- **삭제 누출(60건):** 20, 3, 7.

LLM 모순 필터 경로의 결과는 다음과 같다.

- **현재 정답:** 114, 107, 109.
- **전체 정답:** 136, 130, 135.
- **삭제 누출:** 17, 4, 4.

원문 제외 필터와 분리 필터 사이에 바뀐 행을, 검색 맥락이 바뀌었는지로 나누어 보았다(휴리스틱 경로, Fable 재집계).

- **맥락이 바뀐 행(필터 효과로 볼 수 있는 행):** 동시 선호(coexist) +6, 인용 모순 +2, 새 사실 +1, 정정 −4, 연쇄 변경 −1, 시점 조회 −1로, 합계 +3이다.
- **맥락이 같은 행(노이즈):** 비밀값 삭제 +5와 예약 취소 +6은 모두 맥락이 같은 행이다. 판정 불가가 판정으로 바뀌거나 답변 문장이 흔들린 경우다. 삭제 누출 3건에서 7건으로의 증가(ko-110, 111, 118, 119)도 모두 맥락이 같은 행이라, 분리 필터가 누출을 늘렸다는 근거가 없다. LLM 경로의 누출 변화는 0이다.
- **노이즈 규모:** 맥락이 같은데 답변 문장이 바뀐 naia 행이 35건(LLM 경로 28건)이다. 답변 수준 집계의 차이(전체 정답 127과 141)는 이 노이즈 안에 있다.

## 해석

분리 필터는 원문 제외 필터 대비 동시 선호의 손실을 되돌리고(+6), 정정 사례에서 옛 값을 가리던 효과를 일부 잃는다(−5). 삭제 누출에는 필터 탓으로 볼 수 있는 차이가 없다. 답변 수준 집계는 비결정성(맥락이 같은 행 35건)에 묻혀 어느 필터가 낫다고 말하지 못한다.

기본값은 기전으로 판단해 소유자 결정 항목에 올린다. 필터가 없으면 누출이 20건 대 3~7건으로 명백히 불리하므로 필터는 켠다. 분리 필터를 기본 후보로 두는 이유는 보존 우선 원칙이다. 사용자가 요청한 삭제만 원문을 가리고, 제품이 스스로 내린 대체 판단(틀릴 수 있음)은 원문을 가리지 않는다. 대체가 틀렸을 때 사용자가 말한 값이 완전히 사라지는 쪽(원문 제외)이, 옛 값이 맥락에 보이는 쪽(분리)보다 더 무거운 기억 실패다.

정의상 유의점: archived는 삭제뿐 아니라 decay 보관에도 붙는다. 제품에서는 decay로 보관된 사실의 원문도 최신 회상에서 빠진다.
